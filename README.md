# iMxp - Multimedia Experience

## Overview

**iMxp** is a multimedia educational project designed to introduce prospective students to the Multimedia Engineering program at Universidad Autónoma de Occidente (UAO). The project combines an interactive web portal with an Augmented Reality (AR) mobile application to provide an engaging introduction to the program before students enter university.

## Project Description

iMxp is an innovative initiative that aims to showcase the multimedia engineering career in an interactive and engaging way. Through a combination of web and mobile technologies, the project presents relevant information about the program while incorporating cutting-edge Augmented Reality experiences.

The project features:
- **Interactive Web Portal**: A responsive blog-style website built with Bootstrap that provides information about the program
- **Augmented Reality Experience**: An Android application that allows users to build a cube in AR and learn about the program through interactive elements
- **Blueprint Download**: Users can download technical plans and build their own AR cube

## Features

- 🌐 Responsive web interface for program information
- 📱 Android APK with Augmented Reality experience
- 📋 Downloadable blueprint plans for the AR cube
- 👥 Program information targeted at prospective students
- 🎨 Modern, clean design using Bootstrap framework

## Getting Started

### Prerequisites

- Node.js and npm
- A web browser to view the portal
- Android device (to install and test the APK)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/garayco/imxp.git
cd imxp
```

2. Install dependencies:
```bash
npm install
```

3. Build the project:
```bash
gulp
```

## Usage

### Web Portal

Open `index.html` in your web browser to access the main portal. The site includes:
- Navigation to the home portal and "About" section
- Download links for the AR cube blueprints
- Download link for the Android APK

### Mobile Application

1. Download the `iMxpCubo.apk` file from the portal
2. Install on your Android device
3. Launch the app to experience the Augmented Reality cube
